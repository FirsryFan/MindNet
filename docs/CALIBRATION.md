# MindNet 参数标定协议

**怎么做**：双击打开 `viz/calibrate.html`（`file://` 可直接用）。
**只做必做的三项**：T2 走神（3 分钟）、T5 自信（5 分钟）、T6 成本（1 分钟），合计约 9 分钟；
其余三项是**选做**，用文献/人群默认值就够，别为它们花时间。
**目标**：不是"测准"，而是**让模型先用上你自己的量级**。偏差靠后面的做题反馈继续修
（规则见 `docs/FEEDBACK.md`；本文 §6 只讲怎么接上去）。

---

## 0 三条纪律

1. **能闭式解的绝不做拟合**：每个实验的数据都直接代进模型自己的方程（见 `src/calibration.js`），
   所以你看到的参数是可以手算复核的，不是黑箱吐出来的数。
2. **代理量要说明**：有的量没法直接测（比如"激活水平"），实验里用可观测的代理
   （反应时间当流畅度、正确率当可提取度、自评当成本），每个都写在下面的表里。
3. **不确定就标注**：样本不足时估计器会**原样返回默认值并说明**，不会硬凑一个数。

## 1 分层：必做 vs 选做

判断标准只有一条：**这个参数是"人群有共识的"，还是"只有你自己知道"**。

| 层级 | 实验 | 为什么 | 默认值来自 |
|---|---|---|---|
| **必做** | T2 走神与专注 | 没有人能从文献里猜出你多久走神一次 | 无（`duty = 0.9` 只是占位） |
| **必做** | T5 自信校准 | "觉得有把握"该打几折是个体差异 | 人群平均 `b0 = 1.5` |
| **必做** | T6 成本与目标 | 你愿意花多少力气换多少留存，只有你能回答 | `回忆一次 = 1` 的归一化基准 |
| **选做** | T1 意识容量 | 记忆广度人群值很稳（Cowan 4±1 组块） | `W_DAR = 4.0` |
| **选做** | T3 遗忘速度 | 遗忘曲线量级用 FSRS-4.5 公开拟合参数；且**一道题只有 1 bit，靠这一项也测不准 S** | `legacy_k = 24` 小时 |
| **选做** | T4 再读 vs 主动回忆 | 有元分析结论（Rowland 2014，提取练习 g ≈ 0.5） | `kappa_reread_ratio = 0.5` |

页面上选做项标了「选做」徽章、进度单独计（`必做 x/3 · 选做 y/3`），
参数表里未测的选做项直接显示"用默认"。**跳过的实验不会进 overrides**。

> 为什么把 T3 降级：见 `docs/FEEDBACK.md` §3 —— 二值结果对 `S` 的 Fisher 信息上限
> 只有 `I ≈ 0.0359`，100 道题也只能把 `S` 定到 ±70%。花 20 分钟做一次延迟回忆得到的
> 那个 `S`，并不比 FSRS 的人群值更可信；而几百道题的反馈会慢慢把它拧对。

## 2 六个实验与对应参数

| # | 层级 | 实验 | 产出参数 | 用的公式（与模型同源） | 预计 |
|---|---|---|---|---|---|
| T1 | 选做 | 即刻广度：3→7 个词闪现后回忆 | `attention.capacity.W_DAR` | 正确率跌破 50% 处的 N（线性插值） | 3 分钟 |
| T2 | **必做** | 3 分钟经验取样（走神就点一下） | `rhythm.gate.duty / p_off / p_on / tau_vig_minutes` | 走神占比 = `p₁/(p₁+p₂)`；平均专注段 = `1/p₁`；首尾专注率之比 = `exp(−Δt/τ)` | 3 分钟 |
| T3 | 选做 | 学 8 个词 → 立即回忆 → **几小时后**再回忆 | `memory.dsr.legacy_k`（初始稳定度系数）；同时得到 `S` 与 `R0` | `S = t·c / ((Rt/R0)^(−1/γ) − 1)`，`c = 0.9^(−1/γ) − 1`，`γ = 0.1542` | 两次 |
| T4 | 选做 | A 组再读 / B 组主动回忆 → **第二天**测两组 | `memory.dsr.kappa_reread_ratio` | 两组同初始条件 ⇒ `(SInc_A−1)/(SInc_B−1) = κ_A/κ_B` | 两次 |
| T5 | **必做** | 12 项：先给"把握"0–100 → 再自评是否想起 | `metacognition.belief.b0 / delta` | 二分 `b0` 让预测平均自信 = 实际回忆率；`δ` 取 `\|自信−实际\|` 的 75 分位 | 5 分钟 |
| T6 | **必做** | 问卷：三类动作的费力程度 + 目标留存 | `control.planner.cost_*`、目标留存 | 自评归一化到"回忆一次 = 1" | 1 分钟 |

## 3 每个实验到底在测什么

### T1 意识容量 `W_DAR`
屏幕上依次闪现 N 个词（各 1.2 秒），闪完凭记忆写出来。从 3 个测到 7 个，取"正确率掉到一半"的位置。
**语义**：同时能拿住的激活量 ≈ 项目数（每项激活 ≈ 1）。默认 4（Cowan 3–5 组块 / Oberauer 直接访问区约 4）。

### T2 节律与走神
3 分钟里：每 20 秒自动采样一次，这一段里你点过"我又走神了"就记走神。得到三个量：
- **走神占比** → `duty = 1 − 走神占比`（"在"的时间比例）
- **平均连续专注段** → `p_off = 1/平均段长`（以 tick 计，250ms/tick）
- **前 1/3 与后 1/3 的专注率之比** → 警觉衰减 `τ`（越做越差的程度）

> 依据：Killingsworth & Gilbert 2010 用同样的经验取样法测出清醒时间约 46.9% 在走神。
> 你测出来的可能是 30%，那就是**你自己的**走神率 —— 模型用它，而不是用文献的。

### T3 记忆稳定度 `S`（选做，默认已够用）
模型里有一条可提取度曲线：`R(t) = R0·(1 + c·t/S)^(−γ)`。学一遍后立刻回忆得到 `R0`；
过 t 小时再回忆得到 `Rt`；两个数一代，`S` 就解出来了。

**口径提醒（容易误解）**：`S` 的定义是"可提取度降到 `0.9 × R0` 所需的小时数"，而不是"降到 90%"。
若你的 `R0 = 0.8`，那么 90% 这个目标**永远够不到** —— 此时排程函数返回间隔 `0`，
意思是"先提高编码强度，或者立刻复习"。这不是 bug，是模型在如实告诉你：编码太浅。

由 `S` 还能反推初始稳定度系数 `k = S / R0`（默认 24 小时）—— 它决定"新学的东西能撑多久"。
**不做这一项时**：`k` 保持 24 小时这个默认量级，之后由做题反馈（`docs/FEEDBACK.md`）慢慢修正；
反馈账本里的 `suggestLegacyK()` 会在证据够了以后，反过来建议一个属于你的 `k`。

### T4 再读 vs 主动回忆（选做）
两组各 5 个词，A 组"再读一遍"、B 组"合上材料主动回忆"，第二天测两组留存，各自反解出 `S`。
两组的初始条件相同（同批新词、同初值），所以两组增益之比就是 `κ_reread / κ_retrieval`。

> 依据：提取练习效应（testing effect）。默认 `kappa_reread_ratio = 0.1`，即再读只有十分之一的增益。
> 你的实测可能没这么极端 —— 那就把实测值用上。

### T5 自信校准
逐个词：先给"把握"（0–100），再自评"真的想起了吗"，同时记录**反应时间**当流畅度代理。
- 平均自信高于实际回忆率 ⇒ `b0` 调高（模型里的"先验自信"更足），反之调低；
- `δ` 是"危险区"的门槛：自信 − 实际 > δ 就判为"以为会、其实不会"；
- 输出的**校准度**（平均 |自信−实际|）就是你的元认知准确度，越小越准。

> 依据：Metcalfe 2009（JOL 与流畅性、5-1/1-5 错觉）。人对"方向性不对称"是盲的，所以高估是常态。

### T6 成本与目标
1–5 的费力自评，归一化成"回忆一次 = 1"的成本比 → 决定处方排序里的性价比分母。
"目标留存"直接进排程公式：**85% 目标 ⇒ 间隔 ≈ 1.906 × S**（Wilson 2015 的 85% 规则落点）。
问卷里还顺手对比了"你平时做题正确率"与 85%：太低说明练习偏难，太高说明挑战不够。

## 4 拿到参数之后

标定页右侧会自动生成一段 JSON：

```json
{
  "attention.capacity.W_DAR": 3.5,
  "rhythm.gate.duty": 0.62,
  "rhythm.gate.p_off": 0.0184,
  "rhythm.gate.p_on": 0.0462,
  "rhythm.gate.tau_vig_minutes": 26.4,
  "memory.dsr.legacy_k": 31.2,
  "memory.dsr.kappa_reread_ratio": 0.18,
  "metacognition.belief.b0": 1.28,
  "metacognition.belief.delta": 0.22,
  "control.planner.cost_link": 1.67,
  "control.planner.cost_offload": 0.33,
  "calibration.target_retention": 0.85
}
```

两种用法：
1. **点「保存参数（供扩散视图使用）」** → 存到本机，打开 `viz/index.html` 时自动生效（顶部会显示"已应用 N 个标定参数"）。
2. **手动贴**：把 JSON 传给引擎 —— `createKernel(graph, config, { profile: 'v2', overrides: <这段 JSON> })`。

**没做的实验不会出现在 JSON 里**：缺哪项就用哪项的默认值，不会瞎猜。
**选做项跳过也不影响**：整段 JSON 只剩 T2/T5/T6 的产出时模型照样能跑，而且这是**推荐**用法（见 §1）。

## 5 精度说明（诚实边界）

| 项 | 现状 |
|---|---|
| 样本量 | T1 只有 5 档、T5 只有 12 项 —— 够定**量级**，不够定精细值 |
| 代理量 | T5 用反应时间当"流畅度"；T1 用项目数当"激活量"；T4 的 `S_before` 用 `k×R0` 近似 |
| 一次测量的噪声 | 睡眠、情绪、时间点都会影响；T3 多测几次会明显更稳（但按 §1 的理由，**不建议**为 T3 花这个时间） |
| 选做项的默认值 | 遗忘曲线用 FSRS-4.5 公开拟合参数、记忆广度用 Cowan 4±1、提取练习增益用 Rowland 2014 元分析 —— 都是**人群值**，不是你 |
| 其余参数 | `dynamics.shunting` 的 α/λ、`attention.ignition.T_ign`、`context.goal.β` 等**仍未标定**，用默认值 |
| 结论**不**适用于 | 不能用这些数字去宣称"某人的记忆力如何" —— 它只服务于"这个模型对这个人该怎么排程" |

## 6 反馈闭环：标定只是起点

模型不需要一次标定到位。**每做一道题都是一条新证据**，规则只有一份实现：
`src/feedback.js`（完整推导、诚实边界与三种用法见 **`docs/FEEDBACK.md`**）。

**先记住分工**（2026-09 定案，见 `docs/IO_PROTOCOL.md` §6）：
每条线索的 `S` 由**机制**（`mechanisms/memory.dsr.js`）维护 —— 那是模型的物理；
反馈模块**不改任何节点的 `S`**，它做两件事：给"机制算的 `S` vs 用你的对错估出的 `S`"
出一份**体检对照**（`compareWithGraph`），以及攒够证据后给**参数建议**
（`suggestOverrides`，例如 `memory.dsr.legacy_k`）。

体检用的估计律（只观不写）：

```
p = R0·Ψ(t/S)                        ← 模型考前预测"这次能不能想起来"
e = y − p                            ← 预测误差（y = 1 答对 / 0 答错）
u = 4p(1−p)                          ← 信息量权重：p ≈ 0.5 时最有信息
gain = max(0.05, 0.35/(1 + k/20))    ← 递减增益（k = 这条线索已收过几条证据）
S_est' = S_est · exp(gain · e · u)   ← 单步位移硬上限 ±40%（账本估计，不写回图）
```

两条要点：

1. **为什么不用"答对加分"**：只要目标留存高于 50%，答对永远比答错多，
   那种写法会让估计值单调漂移、永不收敛。用误差 `e` 时，`E[e] = 0` 恰好等于"模型校准"，
   平衡点就是这条线索的真实量级。（旧版 `calibration.refineStability` 就是漂移写法，
   现在只是本模块的兼容别名，规则只有一份。）
2. **它有多准**：一道题只有 1 bit 信息。最优点（`t ≈ 3.9·S`）的 Fisher 信息上限
   `I ≈ 0.0359` ⇒ 100 条到 ±70%、400 条到 ±30%。这是数据的性质，换算法也快不了。
   所以体检调的是**量级**；壳里会一直显示当前的误差下界，不假装精准。

这条通道也是 MindNet 与刷题系统对接的地方：
**推题 → 对错与时间戳 → 机制改 S → 体检偏差 → 调参数**。
壳里点着用（`viz/index.html` 右侧「反馈」卡片）、命令行里批量用（`node tools/feedback.js`）都行。

## 7 复现与自检

```powershell
npm test                        # 109 项（含标定估计器 10 项、反馈 11 项、反馈 CLI 6 项）
node tools/feedback.js demo     # 用模拟学生验证"收敛 / 不漂移"（对照信息论下界）
node viz/build_mechanisms.js    # 生成浏览器用的机制清单（改过机制模块后要重跑）
node viz/build_samples.js       # 生成示例图数据
```

标定页自带自检：用 `viz/calibrate.html?selfcheck=1` 打开，页面底部会写入一份 `<pre id="selfcheck">` 报告
（参数表行数、实验数、必做/选做分层计数、端到端跑一遍估计器、一次真实的反馈演示、localStorage 是否可用）。
