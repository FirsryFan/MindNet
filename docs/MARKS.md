# 手写记号约定（拍照 → AI 判读）

> **这份文件只有一个目的**：让你在纸上花的力气最少、AI 认错的机会最小。
> 记号写在**页边留白**，正文只画范围 —— 因为"页边的手写大字"是 AI 最擅长的，
> "正文里某一个具体的词"是 AI 最容易错的。
>
> 配套：`docs/INGEST.md`（AI 怎么提取、怎么变成卡片和模型输入）。

---

## §1 一张纸长什么样

```
┌──────────────────────────────────────────────────────────────┐
│ #旅行                                          09-25         │  ← 主题 / 日期（都可选）
│                                                              │
│  词│ resilient        ← 类型字 + 竖线 + 照抄的那个词            │
│    │ ...she was remarkably resilient in the face of...       │
│    │                                                         │
│  搭★│ get the hang of                                          │
│    │ It took me a while to get the hang of it.               │
│  句│ └────────────────────────────────────────────┘          │  ← 竖线覆盖两行 = 整句
│    │                                                         │
│  段│ ┌────────────────────────────────────────────┐          │  ← 整段（不抄，正文即内容）
│    │ │ （完整的一段，好几行）                        │          │
│  问│ └────────────────────────────────────────────┘          │  ← 这句我没听清
│    │ ...introduced the ▓▓▓▓ to the audience...               │
└──────────────────────────────────────────────────────────────┘
```

## §2 记号表（全部就这些）

### 2.1 类型字（写在竖线顶端）

**写中文一个字**（不用在脑子里翻译，笔顺也少）：

| 你写 | 念作 | 要不要照抄 | AI 怎么处理 |
|---|---|---|---|
| **词** | 单词 | 要（写在竖线旁） | 词形以**正文**为准，页边只用于核对拼写 |
| **搭** | 搭配 / 短语 | 要 | 同上 |
| **句** | 句子 / 句型 | 不要（正文即内容） | 竖线覆盖的行就是句子 |
| **段** | 语段 | 不要 | 竖线覆盖的多行就是一段 |
| **问** | 疑问 / 没听清 | 要（写一句你的问题） | 不建卡片，进"待解决"清单 |
| **会** | 我已经会了 | — | 只记一笔"看过"，不建卡 |

> 也可以写字母 `W C S T N`（词=W、搭=C、句=S、段=T、问=N），或者数字 `1 2 3 4 5` ——
> **三种写法完全等价**：出来的节点一模一样，不会重复建。
> 顺手用哪个就用哪个，混着写也行。

### 2.2 附加符号（写在类型字**后面**，可以叠）

| 符号 | 意思 | 效果 |
|---|---|---|
| `★` | 重要，必须掌握 | 排进更紧的复习；卡片标记为高优先 |
| `→` | 我要能**说出来 / 写出来** | 额外生成一张"产出型"卡 |
| `!` | 特例（固定说法、不规则变化） | 卡片标记为例外 |
| `?` | 拿不准要不要留 | 卡片标记待确认，你点头后才启用 |

例：`搭★→` = 重要的搭配，而且要能自己用出来。

### 2.3 页面顶部（都可选）

| 写什么 | 例 | 用途 |
|---|---|---|
| 主题 | `#旅行` | 建一个主题节点，这些条目都挂在它下面 |
| 日期 | `09-25` | 记下采集时间 |
| 出处 | `6min#3` | 材料来源（节目名#第几段），写在卡片上方便回查 |

## §3 怎么省力气

### 3.1 短的抄、长的圈（核心规则）

| | 正文里的东西 | 页边你抄的东西 |
|---|---|---|
| 长什么样 | 印刷体，整页密排 | 你的手写大字，孤零零几个 |
| AI 读起来 | **定位到"哪一个词"很容易错** | 最容易读对 |
| 读错的后果 | 提取成隔壁的词、漏字母 | 一般能纠回来 |

所以：**词和搭配顺手抄一下**（两三个词，两秒钟），**句子和段落只画线**。

### 3.2 两条省事通道（想更省就这么做）

| 情况 | 你可以 | 但 AI 必须"说明白" |
|---|---|---|
| **一行里只有一处**要记 | 不抄，只写类型字 + 竖线 | AI 标 `inferred_from_line`（说明"我按整行唯一一处取的"），卡片打上 `scope_from_line` 标签 |
| **一行里多处**要记，但懒得抄 | 在要记的**那个词下面点一个点** | AI 标 `marked_by: "dot"` + 位置描述，卡片打上 `scope_dot` 标签 |

两条通道的产出都会**打标签**，所以你事后能在 Anki 里一键筛出来核对"AI 有没有取错词"。
**如果两样都没做、也没抄**，AI 会拒绝提取（宁可漏，不可错）。

### 3.3 不用圈、不用下划线、不用颜色、不用箭头

- **圈和下划线**：跟印刷体的线、笔误混在一起，AI 分不清是你在标还是纸本来就有；
- **颜色**：拍照白平衡会变，黑白复印直接失效；
- **方向**：纸可能拍歪拍倒，任何靠箭头方向表达意思的记号都不靠谱。

留下来的都是**单笔画、形状独特、不依赖颜色和方向**的记号。

## §4 你实际要做的（30 秒）

1. 听到值得留下的 → 页边画竖线，顶端写一个类型字（词/搭/句/段/问）；
2. 是词或搭配 → 顺手抄在竖线旁边；
3. 想标重要 / 要会说 → 后面补 `★` `→`；
4. 没听清的 → 写 `问` + 一句问题；
5. 拍照，跟一句话说给 AI：

   > 「按 docs/MARKS.md 的记号提取，转成卡片和 MindNet 请求」

一页可以标很多条；句子范围里再标词，AI 会自动把"词 → 句"连起来。

## §5 记号可以随时换

记号本身没有魔法。它们只出现在两个地方：给 AI 的提示词（`docs/INGEST.md` §5）
和转换器里的一张表（`src/ingest.js` 的 `MARK_ALIASES`）。
你觉得 `词搭句段问` 不好写，说一声改成什么都行（比如只写 `1 2 3 4 5`，或者你自己的一套符号）——
流水线不用动，卡片和模型输入都不受影响。

---

## §6 换个科目怎么套

只换"类型字"这一栏，别的全不变：

| 场景 | 类型字 |
|---|---|
| 英语听力（本文） | 词 / 搭 / 句 / 段 / 问 |
| 数学错题 | 错（错在哪）/ 法（方法）/ 点（知识点）/ 缺（缺的前置） |
| 语文作文 | 句（好句）/ 构（结构）/ 词（词汇）/ 问 |
| 代码笔记 | 用（API）/ 式（模式）/ 坑（陷阱） |

**不变的是流水线**：记号 → AI 提取 → 卡片 + 模型输入。换场景只动记号表和卡片模板。
