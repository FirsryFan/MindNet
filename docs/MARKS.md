# 手写记号约定（拍照 → AI 判读）

> **这份文件只有一个目的**：让你在纸上花的力气最少、AI 认错的机会最小。
> 记号写在**页边留白**，正文只画范围 —— 因为"页边的手写大字"是 OCR 最擅长的，
> "正文里某一个具体的词"是 OCR 最容易错的。
>
> 配套：`docs/INGEST.md`（提取与转化流水线）、`docs/TRANSCRIBE.md`（做错了什么 → 复习事件）。

---

## §1 一张纸长什么样

```
┌──────────────────────────────────────────────────────────────┐
│ #travel                                        09-25        │  ← 主题标签 / 采集日期（都可选）
│                                                              │
│   W│ resilient        ← 页边：类型字母 + 范围线 + 照抄内容      │
│    │ ...she was remarkably resilient in the face of...       │
│    │                                                         │
│  C★│ get the hang of                                          │
│    │ It took me a while to get the hang of it.               │
│  S │ └────────────────────────────────────────────┘          │  ← 范围线覆盖两行 = 整句
│    │                                                         │
│  T │ ┌────────────────────────────────────────────┐          │  ← 整段（不抄，正文即内容）
│    │ │ （这一段是完整的语段，3 行以上）              │          │
│  N?│ └────────────────────────────────────────────┘          │  ← 疑问：这行没听清
│    │ ...introduced the ▓▓▓▓ to the audience...               │
└──────────────────────────────────────────────────────────────┘
```

## §2 记号表（全部就这些）

### 2.1 类型字母（写在范围线顶端）

| 记号 | 名称 | 你要不要照抄 | AI 拿到什么 |
|---|---|---|---|
| `W` | **词**（word） | **要**：把词抄在页边 | 词形以**正文**为准，页边用于消歧 |
| `C` | **搭配/短语**（chunk） | **要** | 同上（2–6 个词） |
| `S` | **句子/句型**（sentence） | 不要，正文就是内容 | 范围线覆盖的行 = 句子（OCR 印刷体） |
| `T` | **语段**（text/passage） | 不要 | 范围线覆盖的多行 = 一段 |
| `N` | **疑问/没听清**（note） | 要：写一句你的问题 | 不建卡，进疑问清单 |
| `✓` | 单独写在某行旁 | — | "这句我懂了/这个词我会了" → 只记"看过"，不建卡 |

### 2.2 修饰符（写在类型字母**后面**，可以叠加）

| 记号 | 含义 | 效果 |
|---|---|---|
| `★` | 高优先级，必须掌握 | 排进更短的间隔；卡片标记 `priority=star` |
| `→` | 我要能**产出**（仿写/造句/说出口） | 额外生成一张"产出型"卡，并建反向边 |
| `?` | 我不确定这条要不要留 | 卡片标记 `needs_review`，等你确认后再启用 |
| `!` | 例外/特殊情况（固定说法、不规则变化） | 卡片标记 `exception=true`，复习类型偏"再读" |

例：`C★→` = 高优先级的搭配，而且要能自己用出来。

### 2.3 页面级记号（写在纸的最上面）

| 记号 | 例 | 含义 |
|---|---|---|
| `#主题` | `#travel` | 本批次的主题 → AI 建一个主题 hub 节点，各条目挂上去 |
| 日期 | `09-25` | 采集日期（可选；不确定就不写，我会问你） |
| 来源 | `6min#3` | 材料出处（可选，写短一点：节目名#第几段） |

## §3 三条"为什么这样设计"

### 3.1 为什么短的抄、长的不抄

| | 正文里的内容 | 页边抄写的内容 |
|---|---|---|
| 字体 | 印刷体（有时还带连字符换行） | 你的手写大字 |
| OCR 难度 | 整页密排，**定位到"哪一个词"很容易错** | 空白处孤立几个字，**最容易读对** |
| 出错后果 | 提取成隔壁的词 / 漏字母 | 一般能纠回来 |

所以规则是：**`W`/`C` 照抄到页边**（AI 把页边当条目，正文当例句来源，两全其美），
**`S`/`T` 不抄**（太长），直接用范围线把正文圈出来。

### 3.2 为什么不用圈、下划线和颜色

- **圈/下划线**：和印刷体的下划线、笔误、强调线混在一起，AI 无法区分是"你在标记"还是"纸本来就有"；
- **颜色**：拍照后受白平衡影响，黑白复印直接失效；
- **方向**：纸可能拍歪、拍倒，任何"靠箭头方向表达含义"的记号都不可靠。

留下来的都是**形状独特、单笔画、与常规笔记习惯不冲突**的记号。

### 3.3 为什么宁缺勿错

AI 只被允许做两件事：**读出你写了什么**、**把它结构化**。
所以约定里每一条都带"退化出口"：

- 记号看不清 → 标 `uncertain: true` 并给出位置，**不猜内容**；
- 类型字母没写 → 允许按长度启发式判（≤2 词算 `W`、≤6 词算 `C`、有谓语算 `S`、多句算 `T`），
  但必须标 `inferred_type: true`；
- 页边和正文不一致 → **以正文印刷文本为准**，两边都记下来并标 `conflict: true`。

## §4 你实际要做的（30 秒版）

1. 听的时候，听到值得留下的东西 → 在**页边**画一条竖线，顶端写类型字母；
2. 是词或搭配 → 顺手把它抄在竖线旁边（就抄一次，比抄整句快得多）；
3. 想标优先级/产出 → 在字母后面补 `★` `→`；
4. 没听清的 → 旁边写 `N?` 加一句问题；
5. 拍张照，和一句话一起发给 AI：
   > 「按 docs/MARKS.md 的记号提取，转成卡片和 MindNet 请求」

一次可以标很多条，同一页允许嵌套（句子范围里再标词，AI 会自动连边）。

---

## §5 记号表是可以换的

记号本身没有魔法，**换一套字也一样能用** —— 因为它们只在两个地方出现：
AI 的提示词（`docs/INGEST.md` §5）与转换器的一张常量表（`src/ingest.js` 的 `MARKS`）。
你若觉得 `W/C/S/T` 不好写，告诉我换成什么（比如 `1/2/3/4`、`单/搭/句/段`），
我改这两处就行，流水线不用动。

## §6 其它场景怎么套（抽象）

同一套记号可以覆盖别的科目，只换"类型字母"这一栏：

| 场景 | 类型字母 | 说明 |
|---|---|---|
| 英语听力（本文） | `W` 词 / `C` 搭配 / `S` 句 / `T` 段 / `N` 疑问 | 短项抄、长项圈 |
| 数学错题 | `E` 错在哪 / `M` 方法 / `K` 知识点 / `P` 前置缺失 | `K` 与 `P` 直接对应 MindNet 的节点与"缺前置"诊断 |
| 语文/作文 | `G` 好句 / `R` 结构 / `V` 词汇 / `N` 疑问 | `G` 走"再读+产出"，`R` 建结构节点 |
| 代码/工具 | `A` API / `P` 模式 / `T` 陷阱 | `T`（陷阱）适合挂 `!` 例外标记 |

**不变的是流水线**：记号 → 提取信封 → （知识图补丁 + 呈现卡 + 请求）。
换场景只动"记号表"和"卡片模板"两处。
