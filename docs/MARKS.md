# 手写记号约定

> 目的只有一个：**让你在纸上花的力气最少、AI 猜错的机会最小。**
> 记号写在**页边留白**，正文只画范围 —— 因为页边的手写大字 AI 最容易读对，
> 而"正文里某一个具体的词"最容易读错。
>
> 记号是**开放的**：下面这些只是默认，你随时可以自己加（见 §4）。

---

## §1 默认记号

### 类型字（写在页边竖线顶端，写一个字）

| 你写 | 意思 | 要不要抄到页边 |
|---|---|---|
| **词** | 单词 **或** 搭配（两者不区分） | 要，抄在竖线旁 |
| **句** | 句子 / 句型 | 不要，竖线覆盖正文那几行 |
| **段** | 整段 | 不要 |
| **问** | 疑问 / 没听清 | 写一句你的问题 |
| **会** | 我已经会了 | — |

> 也可以写字母 `W S T N` 或数字 `1 3 4 5`（等价）；**写「搭」也行**，和「词」同义。

### 附加符号（写在类型字**后面**，可叠加）

`★` 重要 · `→` 要能说出来 · `!` 特例 · `?` 拿不准

例：`词★→` = 重要的词或搭配，而且要能自己用出来。

### 页面顶部（可选）

`#主题`（如 `#旅行`）、日期、出处（如 `6min#3`）。

## §2 怎么省力气

### 2.1 短的抄、长的圈

| | 正文里的内容 | 页边你抄的 |
|---|---|---|
| AI 读起来 | 整页密排，**定位"哪一个词"容易错** | 空白处孤零零几个大字，**最容易读对** |
| 读错的后果 | 取成隔壁的词、漏字母 | 一般能纠回来 |

所以：**词和搭配顺手抄一下**（两三个词），**句子和段落只画线**。

### 2.2 两条更省事的写法

| 情况 | 你可以 | AI 必须说明 |
|---|---|---|
| 这一行只有一处要记 | 连抄都不用，只写类型字 + 竖线 | 标 `inferred_from_line`，产出打 `scope_from_line` 标签 |
| 这一行有好几处，懒得抄 | 在要记的**那个词下面点一个点** | 标 `marked_by:"dot"` + 位置描述，产出打 `scope_dot` 标签 |

两条通道都会**打标签**，方便事后筛出来核对"AI 有没有取错词"。
**既没抄、也没说明** ⇒ AI 拒绝提取那一条（宁可漏，不许猜）。

### 2.3 不用圈、下划线、颜色、箭头

- 圈/下划线：和印刷体的线、笔误混在一起，AI 分不清是不是你在标；
- 颜色：拍照白平衡会变，黑白复印直接失效；
- 方向：纸可能拍歪拍倒，靠箭头方向表达意思不可靠。

## §3 你实际要做的（30 秒）

1. 听到值得留下的 → 页边画竖线，顶端写一个字（词/句/段/问）；
2. 是词或搭配 → 顺手抄在竖线旁边；
3. 想标重要 / 要会说 → 后面补 `★` `→`；
4. 没听清 → 写 `问` + 一句问题；
5. 拍照，跟一句话说给 AI：

   > 「按 docs/MARKS.md 的记号提取，转成标准格式和 MindNet 输入」

---

## §4 记号是开放的（重要）

**默认记号只是默认。** 三种扩展方式，都不用改代码：

| 你想加什么 | 怎么做 |
|---|---|
| 一个新的类型字 | 直接写（比如 `法`、`坑`、`☆`），再在清单开头的 `marks` 块里说明它是什么意思 |
| 一个新的含义 | `marks` 块里写 `{"法": {"role": "method", "means": "解题方法/套路"}}` |
| 一个不属于任何类型的备注 | 不声明也行 —— 归到"未分类"，**照样收进标准输出，不会丢** |

**`role`（角色）决定它去哪** —— 这是唯一需要理解的一个概念：

| role | 去哪 |
|---|---|
| `item` | 进知识图（可复习的单元：词、搭配、知识点…） |
| `passage` | 进知识图（整句 / 整段） |
| `method` | 进知识图，作为"方法 / 技巧"节点 |
| `question` | 不进图，进"待解决" |
| `known` | 不进图，只记一笔 |
| `note` | 不进图，留在标准输出里（提醒 / 坑） |
| `other` | 不进图，留在标准输出里等你归类 |

你写了一个 AI 不认识、也没声明的记号 → 它**按"未分类"收下**（内容不丢），
结果里提醒你一句。补一条声明，它就按你声明的角色走。

---

## §5 换个科目怎么套

只换"类型字"这一栏，别的全不变：

| 场景 | 类型字 |
|---|---|
| 英语听力 | 词（含搭配）/ 句 / 段 / 问 |
| 数学错题 | 错（错在哪）/ 法（方法）/ 点（知识点）/ 缺（缺的前置） |
| 语文作文 | 句（好句）/ 构（结构）/ 词（词汇） |
| 代码笔记 | 用（API）/ 式（模式）/ 坑（陷阱） |
