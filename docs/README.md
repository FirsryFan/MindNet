# MindNet 文档索引

> **文档不少，但按用途只分四类。** 你只需要记住第一类里那两三本。

---

## ① 我要用它（使用者）

| 文档 | 什么时候看 |
|---|---|
| **`PROMPT.md`** | **最先看这本。** 你要在手机/网页版 AI 里拍照提取时，复制这里的提示词 |
| `INGEST.md` | 记号怎么用、AI 提取出来的清单长什么样、怎么变成模型的输入 |
| `CALIBRATION.md` | 做那几个小实验，把参数换成你自己的（只做必做三项即可） |
| `FEEDBACK.md` | 做完题怎么记账、模型准不准怎么看（`compare` / `params`） |
| `IO_PROTOCOL.md` | 想直接把数据喂给模型时看的协议（`mindnet.run/1` / `mindnet.result/1`） |

## ② 我要改它（开发者 / 未来的会话）

| 文档 | 内容 |
|---|---|
| `MODEL_v2_MATH.md` | **模型的数学**：状态空间、全部方程、参数表、可证伪预测（改模型先读这本） |
| `PLUGIN_ARCHITECTURE.md` | 机制插件：槽位、模块清单契约、不变量守卫（加一个机制按这本做） |
| `MEMORY_RECORD.md` | 跨会话记录：已经做到哪、验证过什么、还有哪些没做（**不是使用说明**） |
