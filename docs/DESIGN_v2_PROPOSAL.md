## 0. 一句话

v1.1 是一个**规则自洽的扩散器**，不是**脑/学生的模型**：它把"激活"和"记忆"混成了一个 `state`，没有容量、没有提取练习、没有失败内容，输出是两个数而不是动作。
v2 的路线是：**把你自己理论里已经写下的参数（`R_n`、提取历史 K、亚阈积累、思维容量、三类卡点）在引擎里补齐**，并把输出从"Gap/Penalty 两个数"改成"**诊断 → 可执行指令 → 反事实预测**"。

这不是把 v1.1 推翻——v2 设计成**可退化为 v1.1**（见 §7），旧语义可逐位复现。

## 2. 设计判据（我怎么决定一个机制配不配进模型）

四条硬判据，缺一不进：

1. **现象可指认**：必须对应一个有名字的学习现象（间隔效应、提取练习效应、合意难度、前摄/倒摄抑制、自动化、元认知偏差……），不接受"这样更像脑"。
2. **可计算、无 AI、可复现**：纯函数 + 确定性；必须用到随机时，用可播种的伪随机，同一 seed 逐位可复现。
3. **可证伪**：必须能写出"模型错了会怎样"的模拟断言（曲线形状或数量关系）。写不出来的机制不进核心。
4. **能改变一个决定**：如果它不改变"今天练什么、怎么练"，就只能做派生指标，不进动力学。

外加一条纪律：**一个机制最多加一个参数**（防止参数堆砌导致不可证伪）。

## 3. 机制诊断：v1.1 的九处缺口

每条格式：现象 → v1.1 实际行为 → 学生场景后果 → v2 方向。

**D1 复习不改变遗忘速度。**
`S = k·ms`（k=24，`memory.js:27`），复习后 `ms=1.0` ⇒ `S` 永远回到 24 小时。→ 后果：**间隔提取排不出日程**，模型无法告诉学生"这条可以放到 7 天后"。→ v2：把 `S` 变成独立状态，由复习历史增长。

**D2 激活没有容量、没有竞争。**
`step()` 对所有 `state != INACTIVE` 的源节点传播，达标即点亮，没有上限（探针 2）。→ 后果：模型无法区分"这条你没学会"和"这条你会、但同时涌进来的太多"，也无法解释"被一堆相似概念搞混"。→ v2：意识带宽（软预算）+ 竞争。

**D3 入边取最大值。**
`incoming_max`（`diffusion.js:167-176`）。→ 后果：**10 条弱线索不如 1 条刚过线的线索**；"多角度理解"在模型里没有回报，而你的 Application_Protocol §8「增加连接类型（结构/情境/行动/自我）」正是靠多线索生效的。→ v2：求和 + 饱和。

**D4 距离没有代价。**
每跳的 `Impact = ms_源 × ls × AL_源`，而 `AL_源` 对已点亮节点恒为 1.0，所以信号只按单条边的 `ms·ls` 衰减，不沿路径累乘。→ 后果：**五步推理和一跳回忆一样容易**，模型的"难题"概念只剩阈值。→ v2：传播量用源节点的**当前激活**（连续量）而不是常数 1.0，路径自然衰减。

**D5 "永久亮着"把激活和记忆混为一谈。**
`diffusion.js:205-206`：一旦 `CONSCIOUS`/`SUBCONSCIOUS`，本次扩散内永不改变，但继续向外传播。→ 后果：扩散只会单调增长，**走神、中断、干扰、想不起来**这些真实事件在模型里不可能出现；而 Executive_Architecture §4.1「走神（认知层浪潮盖过意识指挥）」是你要建模的现象之一。→ v2：只有**注意焦点/目标**常亮（这才对应"学生把问题按在脑子里"），其余激活按 λ 衰减。

**D6 失败只有计数，没有内容。**
失败只做 `visit_count += 1`（`diffusion.js:193-195`），KC 里只出现 `√visit_count`。→ 后果：**无法区分 Executive_Architecture §4.2 的三类卡点**——空（没候选）/ 慢（等太久）/ 容量太大（候选过多），而这三类的处方完全相反（补入口 / 降单步深度 / 写下来释放工作记忆）。→ v2：把失败分类，并分别映射到指令。

**D7 没有检索采样、没有情境/目标偏置。**
`R_n`（可检索性）、`T`（思维温度）、`d_v(C)`（上下文调制）在 Application_Protocol §1 里是三个要提升的参数，引擎里**一个都没有**（负向断言见 §1 搜索范围）。→ 后果：模型没法表达"换个入口就想起来了"（§3 提升随机访问）和"用目标把无关联想压下去"（§15 设定上下文）。→ v2：检索采样 + 目标偏置。

**D8 衰减只发生在"打开软件"那一刻。**
`memory.js:37-58` 只有 `update_global_memory` 一条路径，且复习=把 ms 拉满，不区分**再读 / 主动提取 / 失败后对答案**。→ 后果：模型无法表达提取练习效应，也无法表达"看答案很爽但没用"。→ v2：复习三档 + 环节末巩固（"睡觉"）。

**D9 KC 不可执行。**
`get_kc()` 返回两个数（`diffusion.js:254-266`）。你的 Application_Protocol 的落地单位是**指令**（17 条动作），中间缺一层"诊断 → 选指令"。→ v2：输出诊断 + 指令 + 预测增益。

补充一条不算缺口但要注意的：`Penalty` 用的是**跨扩散累计**的 `visit_count`，同一得分既惩罚"刚失败"也惩罚"一年前失败"（探针 5）。

### L1 快层（脑的约束）

| 机制 | 公式 / 规则 | 修的缺口 | 依据 |
|---|---|---|---|
| 连续激活 | `a_v(t+1) = clamp(a_v(t)·(1−λ) + g(drive_v), 0, 1)`，`g(x)=1−e^(−x/κ)` | D4 | Collins & Loftus 的衰减扩散（你的 Cognitive_Architecture §2.3 引用） |
| 求和入边 | `drive_v = Σ_u a_u·R_u(t)·ls_uv + β·goal_v` | D3 | 证据汇聚 / fan 效应 |
| 意识带宽（**软预算**） | 每个候选占用 `a_v`，总预算 `W`；按 `(score 降序, id 升序)` 依次准入，超出者留在亚阈 | D2 | 你的 Executive_Architecture §5.1「强度相关而非纯容量」 |
| 概率点火 | `P(点亮) = σ((drive_v − CT_v)/T)`，`T=0` 时退化为 v1.1 的硬阈值 | — | 让"这次想起来／下次没想起来"成为可复现事件（带 seed） |
| 亚阈积累 | 未准入但 `a_v ≥ ST` 的节点：`acc_v += a_v`（有上限、跨轮衰减），下轮 `drive` 加上 `acc_v` | D6 | Application_Protocol §17「亚阈积累，不丢弃」 |
| 目标偏置 | `goal_v = 与当前目标节点的相似度`（先做最简单版：目标节点的出边邻域 = 1，其余 0） | D7 | Application_Protocol §15「设定上下文」 |
| 焦点常亮 | 只有**起点/注意焦点**保持 `a=1.0`，其余全部衰减 | D5 | 工作记忆里"按着不放"的是目标，不是一切 |

### L2 慢层（记忆的规律）

状态：`R0`（编码强度，等价于 v1.1 的 `ms` 初值）、`S`（稳定度，小时）、`last_review`、`history[]`（时间/间隔/结果/努力度）、`kind`（陈述性/程序性）。

```
可提取性：   R_v(t) = R0_v · exp(−(now − last_review_v) / S_v)      # 就是 v1.1 的 ms(t)，S 不再等于 k·R0
```

复习三档（修 D1、D8）：

| 复习类型 | S 更新 | 含义 |
|---|---|---|
| 再读（被动冲刷） | `S ← S·(1 + k_rr·(1−R))`，`k_rr` 很小 | 看一遍很熟，但遗忘速度几乎没变（Executive §2.3「被动冲刷」） |
| 主动提取成功 | `S ← S·(1 + k_rs·(1−R))`，`k_rs ≫ k_rr` | 越难想起来却想起来了（R 低），增益越大 ⇒ **间隔效应自动出现** |
| 提取失败 + 对答案 | `S ← S·(1 + k_rf·closeness·(1−R))`，`closeness = drive/CT` | "差点想起来"的合意难度；同时把增益写到**缺的那条边**上（见 L3） |

巩固（"睡觉"，每个学习环节结束调用一次）：本环节被点亮的节点 `S += replay 奖励`；**未被共同激活的边下调度**（`ls ← ls·(1−downscale)`）。这同时产生两个真实效应：睡一觉更牢、不用就忘（突触下调）。

类型差异：**程序性节点**走幂律练习曲线（S 增益随练习次数递减），累计 N 次成功后 `automation = true` ⇒ `CT` 降低、带宽占用≈0。对应 Application_Protocol §6「自动化只能靠重复 + 正确反馈长出来」。

> 关于遗忘律的选择：你的 Cognitive_Architecture §3.8 用的是 ACT-R 幂律 `B_n(t)=ln(Σ t_k^(−d))`；v1.1 换成了指数。
> v2 建议**默认指数 + 稳定度 S**（因为只有它给出可解释的"半衰期"，才能排出具体间隔），同时保留 `decay_model: 'exponential' | 'power_law'` 开关。这是需要你拍板的取舍之一（幂律更贴近你那篇论文，但"下次该几天后复习"要从幂律反解，解释成本高）。

### L3 控制层（学生的行为）

**卡点诊断**（对齐 Executive_Architecture §4.2 / §4.3，全部可由引擎状态算出）：

| 诊断 | 可计算判据 | 你文档里的处方（指令库） |
|---|---|---|
| 空（缺入口/缺前驱） | `drive < ST` 且入边传不到 | 增加入边 / 降低门槛（弱线索试探）/ 增加连接类型 |
| 弱（差点想起来） | `closeness = drive/CT ∈ [0.6, 1)` | 降低门槛（弱线索试探）/ 增强印象（合上材料主动回忆）/ 间隔提取 |
| 慢（频率不够） | 目标点亮轮次 > 阈值 | 降单步深度 / 先退到高频轻任务 / 提交（线索→知识→操作→边界） |
| 超载（容量） | 被带宽挤出的候选数 > 0 | 写下来释放工作记忆 / 一次只取一个 / 拆簇——**明确标注"这不是知识缺口"** |
| 初筛错 | 错误分支先到 CT，目标未亮 | 更正错误（此路不通）/ 强制补完整推理链 |
| 孤立 | 无入边且非起点 | 增加入边 / 增加连接类型 |

**元认知四象限**（新，学生最特有的偏差）：
把学习者的**自信度 belief** 与**实际可提取性 R** 分开存。`belief` 模拟"看懂了/感觉熟"的直观感受（主要来自 R0 与激活流畅度），而**不含提取历史**——这正是偏差的来源。

| | 高 R（真会） | 低 R（真不会） |
|---|---|---|
| **高 belief** | 维持（低优先级） | **危险区**：学生最可能跳过、最该练 |
| **低 belief** | 过度焦虑区：不必再练，该做的是"确认" | 真空白：正常学 |

**反事实规划器**：引擎是确定性的，所以可以对每个候选干预**在副本上模拟**——"现在对 polar 做一次提取练习，3 天后 `solve_triangle` 的可达性提高多少"。输出按 `预测增益 / 预计代价` 排序的今日清单。这是 v1.1 完全没有、而对学生最有价值的一层。

### L4 输出（KC v2）

- **保留** `kc` / `target_steps` / `targets_all_reached` / `final_states` 四个字段（协议不破）。
- `kc_v2`：把 Gap 拆成 **缺前驱 / 线索弱 / 竞争失败**（后者**不计入** Gap）；Penalty 改成**时间衰减的失败证据** `Σ exp(−Δt/τ)`（修 D6、探针 5）。
- `diagnosis[]`：每个问题节点的卡点类型 + 建议指令 id + `expected_gain`（来自反事实模拟）。
- `metacognition`：危险区/焦虑区清单。
- `internalization`：内化深度派生指标（`|Reach|`、`type_div`、`ΣW_out`、`ΣW_in`、`Clarity`）——这正是你 Application_Protocol §1 那张参数表的可测化，**纯派生、不改动力学**。
